# Vaia

pnpm monorepo containing the Vaia CLI, SDK and OpenAPI contract.

- [CLI usage](apps/cli/README.md)
- [SDK installation](packages/sdk/README.md)
- [Release and hotfix conventions](docs/releasing.md)

Use the pnpm version declared in `package.json`. Build and check both components
with `pnpm build`, `pnpm typecheck` and `pnpm test`.
