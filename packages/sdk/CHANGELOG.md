# Changelog

## 0.1.0 (2026-10-28)

### Features

* Add a typed ESM client for the Vaia API, with configurable authentication, base URL, headers and fetch implementation.
* List study sets and their subsets, with options for archived sets and subset progress.
* List flashcards with cursor pagination and filters, and create, update, delete or move flashcards.
* List, create, update and delete study set tags.
* Expose OpenAPI-generated types and distinct errors for API responses and network failures.
