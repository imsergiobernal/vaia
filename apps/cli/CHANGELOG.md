# Changelog

## 0.1.0 (2026-11-14)

### Features

* Browse study sets and subsets through commands or an interactive menu.
* List, create, update, move and delete flashcards, including bulk updates.
* List and manage tags for study sets.
* Configure the Vaia API token and URL or supply them through environment variables.
* Use structured TOON output for data commands and request complete API responses.
